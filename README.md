# Sistema PROAP

Crie a interface inicial de um sistema web chamado Sistema PROAP — Cadastro e Acompanhamento Social. Todo o sistema deve estar em português brasileiro, com visual profissional, acolhedor, organizado e responsivo para computadores e celulares. Use navegação lateral no computador e menu adaptado no celular. Crie as seguintes páginas: 1) Painel inicial com indicadores ilustrativos; 2) Famílias, com busca, filtros e listagem; 3) Cadastro e edição de famílias; 4) Pessoas e integrantes vinculados às famílias; 5) Ficha familiar com abas de dados, integrantes, demandas, atendimentos e encaminhamentos; 6) Demandas sociais com categorias e status; 7) Histórico de atendimentos em ordem cronológica; 8) Aulas e modalidades; 9) Turmas fixas com professor responsável, dias, horários, local e capacidade; 10) Matrículas com status, data de ingresso e responsável legal; 11) Frequência por encontro, com presença, falta, falta justificada e aula cancelada; 12) Relatórios sociais e educacionais; 13) Administração de usuários e perfis. Use dados exclusivamente fictícios e claramente identificados como demonstração. Não utilize dados reais. Nesta etapa, crie somente a interface navegável e dados de demonstração locais; não conecte banco de dados, não implemente autenticação falsa como se fosse segurança real e não publique o sistema. Organize o código para permitir integração posterior com banco de dados e autenticação reais. Não mostre indicadores fictícios como se fossem resultados reais da PROAP. Priorize a clareza dos formulários, acessibilidade, pesquisa rápida e prevenção de cadastros duplicados. Não implemente ainda dados pessoais reais nem informações sensíveis.
